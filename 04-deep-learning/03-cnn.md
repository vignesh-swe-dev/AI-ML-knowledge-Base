# Convolutional Neural Networks (CNN)

## Concept
Networks that use convolution filters to detect spatial patterns in images.

## Formula / Core Idea
Convolution, pooling, then fully connected layers.

## When to Use
Image classification, object detection, medical imaging.

## Example
Classic architectures: LeNet, VGG, ResNet. Use transfer learning with pretrained models.

## Key Points
- Filters learn edges, then shapes, then objects
- Pooling reduces size
- Data augmentation helps
- Transfer learning saves data and time
