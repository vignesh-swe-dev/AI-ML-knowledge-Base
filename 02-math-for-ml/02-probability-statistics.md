# Probability and Statistics

## Concept
Probability models uncertainty. Statistics draws conclusions from data.

## Formula / Core Idea
Bayes: P(A|B) = P(B|A) P(A) / P(B). Mean, variance, standard deviation. Normal distribution.

## When to Use
Naive Bayes, evaluating models, A/B tests, understanding data.

## Example
If 1% of emails are spam and a filter is 95% accurate, Bayes helps compute the real chance an flagged email is spam.

## Key Points
- Mean, median, mode
- Variance and standard deviation
- Conditional probability and Bayes theorem
- Common distributions: normal, binomial, Poisson
- Correlation is not causation
