# Python Fundamentals

## Concept
Python is the main language for AI/ML because of its simple syntax and rich libraries.

## Formula / Core Idea
Core building blocks: variables, data types, lists, dicts, loops, functions, classes.

## When to Use
Every ML task: data loading, cleaning, modelling, automation.

## Example
```python
def square(x):
    return x * x

nums = [1, 2, 3]
print([square(n) for n in nums])
```

## Key Points
- Master list comprehensions and dictionaries
- Learn to read errors and tracebacks
- Use virtual environments (venv or conda)
- Write small functions and test them
