# Backpropagation and Optimizers

## Concept
Backpropagation computes gradients layer by layer using the chain rule. Optimizers use them to update weights.

## Formula / Core Idea
Forward pass, compute loss, backward pass, update. Optimizers: SGD, Momentum, Adam.

## When to Use
Training every neural network.

## Example
Adam with lr=0.001 is a common starting point.

## Key Points
- Vanishing and exploding gradients
- Batch normalisation stabilises training
- Dropout and weight decay reduce overfitting
- Early stopping saves time
