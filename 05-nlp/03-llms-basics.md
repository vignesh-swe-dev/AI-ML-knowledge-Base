# LLM Basics

## Concept
Large Language Models are Transformers trained on huge text to predict the next token.

## Formula / Core Idea
Pretraining, instruction tuning, RLHF. Use via prompting, RAG, or fine-tuning.

## When to Use
Chatbots, summarisation, coding help, extraction.

## Example
Prompt: 'Summarise this paragraph in 2 lines.'

## Key Points
- Tokens and context window
- Temperature controls randomness
- Hallucinations are possible, verify output
- RAG grounds answers in your documents
