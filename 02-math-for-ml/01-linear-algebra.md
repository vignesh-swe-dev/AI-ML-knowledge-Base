# Linear Algebra

## Concept
Data and model parameters are stored as vectors and matrices.

## Formula / Core Idea
Dot product: a . b = sum(a_i * b_i). Matrix multiplication: C = A B. Eigen: A v = lambda v.

## When to Use
Representing datasets, neural network layers, PCA.

## Example
A dataset with 100 rows and 5 features is a 100 x 5 matrix.

## Key Points
- Vectors, matrices, tensors
- Transpose and inverse
- Eigenvalues and eigenvectors power PCA
- Matrix shapes must match for multiplication
