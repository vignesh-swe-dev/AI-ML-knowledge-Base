# Calculus and Optimization

## Concept
Training a model means minimising a loss function. Derivatives tell us which way to move.

## Formula / Core Idea
Gradient descent: w = w - lr * dL/dw

## When to Use
Training any model with learnable parameters.

## Example
Minimise L(w) = (w - 3)^2. Gradient = 2(w - 3). Repeated steps move w toward 3.

## Key Points
- Derivative = slope
- Gradient = vector of partial derivatives
- Learning rate too high diverges, too low is slow
- Chain rule underlies backpropagation
