# Machine Learning Overview

## Concept
ML lets computers learn patterns from data instead of being explicitly programmed.

## Formula / Core Idea
Types: Supervised (labelled data), Unsupervised (no labels), Reinforcement (reward based).

## When to Use
When rules are too complex to code by hand but data is available.

## Example
Predicting house price (supervised regression). Grouping customers (unsupervised clustering).

## Key Points
- Typical workflow: collect, clean, split, train, evaluate, deploy
- Overfitting: great on training data, poor on new data
- Underfitting: too simple to learn the pattern
- Always split data into train, validation and test sets
