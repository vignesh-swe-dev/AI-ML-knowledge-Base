# Matplotlib

## Concept
Matplotlib is the base plotting library in Python. Seaborn builds on it.

## Formula / Core Idea
Figure and Axes objects hold plots.

## When to Use
Visualising distributions, trends and model results.

## Example
```python
import matplotlib.pyplot as plt
plt.plot([1,2,3],[2,4,6])
plt.xlabel('x'); plt.ylabel('y')
plt.show()
```

## Key Points
- Always label axes and add titles
- Histogram for distribution, scatter for relationships
- Use seaborn for statistical plots
